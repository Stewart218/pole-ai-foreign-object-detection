# 最终模型评估报告

## 1. 项目背景

本项目针对输电线路异物检测任务，基于YOLOv8目标检测算法，
构建面向输电线路巡检场景的智能检测模型。

项目目标：

- 自动识别输电线路上的典型异物；
- 降低人工巡检成本；
- 提高异常隐患发现效率。


检测类别包括：

|类别|英文类别|
|-|-|
|鸟巢|bird_nest|
|气球|balloon|
|塑料袋|plastic_bag|
|其他异物|other_foreign_object|


---

# 2. 最终模型说明


## 2.1 模型结构

最终模型采用：

YOLOv8n

并结合：

- 类别均衡数据增强
- 小目标增强策略
- AdamW优化器
- 超参数调整


最终权重：models/best_model.pt

# 5. 最终测试结果

| ---- | ---- |
| Precision | 0.900 |
| Recall | 0.917 |
| mAP@0.5 | 0.913 |

测试环境：

- Framework：Ultralytics YOLOv8

---

## 5.2 各类别检测性能分析


最终模型在不同类别上的检测结果如下：


|类别|图片数量|Precision|Recall|mAP@0.5|
|-|-|-|-|-|
|bird_nest|2|0.979|1.000|0.995|
|balloon|3|0.660|0.667|0.665|
|plastic_bag|2|0.978|1.000|0.995|
|other_foreign_object|2|0.983|1.000|0.995|


分析：

（1）鸟巢类别：

模型对鸟巢目标具有较强检测能力，Precision和Recall均接近1，说明该类别目标特征明显，模型能够稳定提取其视觉特征。


（2）塑料袋类别：

塑料袋类别检测效果较好，能够满足实际检测需求，但由于部分塑料袋目标尺寸较小、透明度较高，在复杂背景下仍可能出现漏检。


（3）其他异物类别：

模型对于该类别具有较高检测精度，说明经过数据增强后，模型对非典型异物具有一定泛化能力。


（4）气球类别：

气球类别检测性能相对较低：

- Precision：0.660
- Recall：0.667
- mAP@0.5：0.665

主要原因：

- 气球目标尺寸较小；
- 部分气球颜色与背景接近；
- 数据集中气球样本数量有限；
- 不同拍摄角度导致目标形态变化较大。

# 8. 困难样本与泛化能力分析


为了进一步验证模型实际应用能力，选取前期检测效果较差的困难样本进行测试。


## 8.1 气球类别


测试情况：

- 置信度范围：
0.79 ~ 0.94


分析：

模型能够检测大部分气球目标。

但对于：

- 小尺寸气球；
- 背景颜色接近；
- 目标边缘模糊；

仍存在一定漏检风险。


---

## 8.2 鸟巢类别


测试情况：

- 置信度范围：
0.67 ~ 0.90


分析：

鸟巢具有明显纹理结构：

- 枝条形态明显；
- 与输电杆塔环境具有较强关联；

因此模型检测稳定。


---

## 8.3 塑料袋类别


测试情况：

- 置信度范围：
0.50 ~ 0.92


分析：

模型能够识别大部分塑料袋目标。

但由于塑料袋：

- 形状变化大；
- 透明度较高；
- 易受到光照影响；

部分极小目标仍可能漏检。


---

## 8.4 其他异物类别


测试情况：

- 置信度范围：
0.62 ~ 0.67


分析：

该类别包含多种不同类型异物，类别内部差异较大。

部分复杂背景样本仍存在检测困难。

# 9. 当前模型性能瓶颈


虽然最终模型满足项目要求，但仍存在以下不足。


## 9.1 数据规模限制


当前数据集规模：

- 原始图片：133张


数据规模较小，导致模型对于真实线路环境覆盖不足。


实际环境中还可能存在：

- 不同天气；
- 不同拍摄距离；
- 不同光照条件；
- 不同线路结构。


---

## 9.2 小目标检测能力有限


部分异物：

- 占图像比例较小；
- 像素信息不足；
- 与背景相似。


导致：

- 置信度降低；
- Recall下降。


---

## 9.3 类别间特征差异较大


例如：

鸟巢：

- 纹理明显；
- 形态稳定。


气球：

- 颜色变化明显；
- 形态变化大。


不同类别之间学习难度存在差异。
