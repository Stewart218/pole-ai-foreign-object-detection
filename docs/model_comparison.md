# YOLOv8输电线路异物检测模型优化对比报告


## 1. 实验目的

基于第二周完成的 YOLOv8n Baseline 基线模型，为进一步提升输电线路异物检测任务中的目标检测精度，第三周开展多组差异化优化实验。

本阶段主要从三个方向进行优化：

1. **模型结构优化**
   - 更换更高容量 YOLOv8 模型变体；
   
2. **训练策略优化**
   - 调整学习率；
   - 更换优化器；
   
3. **数据策略优化**
   - 强化困难样本数据增强；
   - 提升模型对于小目标、遮挡目标以及复杂背景目标的适应能力。


通过对比不同实验方案中的：

- Precision
- Recall
- mAP@0.5
- mAP@0.5:0.95
- 推理速度

综合评价不同优化策略的有效性，并确定最终模型方案。

# 3.2 Experiment 1

# YOLOv8s模型规模提升实验


## 优化策略

将模型由：

```
YOLOv8n
```

替换为：

```
YOLOv8s
```


通过增加网络深度和参数量，提高模型特征提取能力。


## 实验目的

验证：

> 增大模型规模是否能够提升输电线路异物检测精度。


---

## 实验结果


|指标|Baseline YOLOv8n|YOLOv8s|
|-|-|-|
|最佳Epoch|40|61|
|Precision|0.5316|0.8977|
|Recall|0.6179|0.4958|
|mAP50|0.6382|0.5456|
|mAP50-95|0.2751|0.2047|


---

## 实验分析


### 优点

YOLOv8s相比Baseline：

- Precision明显提升；
- 误检数量下降；
- 背景特征区分能力增强。


说明：

更大的模型具有更强的特征表达能力。


---

### 缺点


但是：

- Recall下降；
- mAP50下降；
- mAP50-95下降。


原因分析：

当前数据集规模较小：

- 原始图片仅133张；
- 场景变化有限；
- 小目标样本数量不足。


更大的模型容易：

1. 对训练数据过拟合；
2. 学习到局部特征；
3. 泛化能力不足。


---

## 结论


YOLOv8s模型适用于：

- 大规模数据集；
- 场景复杂任务。


但当前小规模输电线路异物检测任务中：

> 单纯增加模型规模无法有效提升整体检测性能。

# 3.3 Experiment 2

# 学习率与优化器优化实验


## 优化策略


相比Baseline：

调整：

```text
optimizer:
auto → AdamW


learning rate:

0.01 → 0.001
```


---

## 实验目的


验证训练策略调整对于模型收敛和检测性能的影响。


---

## 实验结果


|指标|Baseline|AdamW优化|
|-|-|-|
|最佳Epoch|40|35|
|Precision|0.5316|0.6688|
|Recall|0.6179|0.5885|
|mAP50|0.6382|0.6768|
|mAP50-95|0.2751|0.2323|


---

## 性能变化


|指标|变化|
|-|-|
|Precision|+13.72%|
|Recall|-2.94%|
|mAP50|+6.01%|


---

## 实验分析


AdamW优化器相比默认策略：

优势：

1. 参数更新更加稳定；
2. 降低训练过程震荡；
3. 提升分类准确率。


实验结果显示：

mAP50达到：

```
0.6768
```

为所有实验最高。


说明：

对于当前小规模输电线路异物数据集：

> 优化训练策略比增加模型复杂度更加有效。


---

# 3.4 Experiment 3

# 困难样本强化数据增强实验


## 优化策略


针对Task1困难样本分析结果：

主要问题：

- 小目标漏检；
- 遮挡目标识别困难；
- 背景复杂导致误检。


增加增强策略：

```text
mosaic

mixup

copy_paste

rotation

scale

hsv增强
```


---

## 实验目的


提高模型对于：

- 小目标；
- 复杂环境；
- 不同拍摄条件

的泛化能力。


---

## 实验结果


|指标|Baseline|Augmentation|
|-|-|-|
|最佳Epoch|40|43|
|Precision|0.5316|0.5934|
|Recall|0.6179|0.6046|
|mAP50|0.6382|0.5928|
|mAP50-95|0.2751|0.1634|


---

## 实验分析


增强策略提高了：

- 部分场景适应能力；
- Recall保持水平。


但是整体mAP下降。


原因：

当前数据规模较小：

增强比例过高导致：

1. 图像分布发生变化；
2. 人工增强样本与真实环境存在差异；
3. 小目标结构受到破坏。


---

## 结论


数据增强需要针对真实困难样本设计。


简单增加增强强度：

并不能保证性能提升。

# 6. 无效尝试分析


## 6.1 单纯扩大模型规模


问题：

数据规模不足。


导致：

- 模型容量无法充分发挥；
- 出现过拟合。


---

## 6.2 过强数据增强


问题：

增强数据与真实环境存在差异。


导致：

- 特征学习困难；
- 检测精度下降。


---



# 7. 最优模型方案确定


综合考虑：

|评价因素|权重|
|-|-|
|检测精度|40%|
|漏检控制|30%|
|模型复杂度|20%|
|部署性能|10%|


最终选择：


# YOLOv8n + AdamW + 学习率优化模型


---

## 选择原因


### 1. 精度最高


mAP50：

```
0.6768
```


超过Baseline：

```
0.6382
```


---

### 2. 模型规模保持较小


相比YOLOv8s：

- 参数更少；
- 推理速度更快；
- 更适合边缘设备部署。


---

### 3. 更符合输电线路巡检场景


实际巡检设备通常：

- 算力有限；
- 需要实时检测。


因此：

轻量化模型+训练优化方案更加适合工程应用。


---

# 9. 后续优化方向


1. 增加真实输电线路困难样本；

2. 针对小目标进行高分辨率训练；

3. 使用目标裁剪增强；

4. 开展类别级别过采样；

5. 引入注意力机制；

6. 进行模型轻量化部署。


---

# 总结


通过三组优化实验发现：

- 增加模型规模并不能保证小数据集性能提升；
- 学习率和优化器优化能够有效改善模型性能；
- 数据增强需要结合实际困难样本进行设计。


最终确定：

> YOLOv8n + AdamW优化策略模型

作为后续输电线路异物检测系统的最佳模型方案。
