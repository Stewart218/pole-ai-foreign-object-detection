# 输电线路异物智能检测项目复盘总结

## 1. 项目背景与目标

本项目面向输电线路巡检场景，基于深度学习目标检测技术，实现对鸟巢、气球、塑料袋以及其他异物的自动检测与定位。

项目目标： - 构建完整目标检测数据集； - 完成YOLO模型训练与优化； -
提升小目标异物检测能力； - 开发可演示的端到端检测系统。

# 3. 数据集构建过程复盘

## 3.1 原始数据

初始数据规模：

-   图片数量：133张
-   分辨率：1408×768

类别：

  类别       名称
  ---------- ----------------------
  鸟巢       bird_nest
  气球       balloon
  塑料袋     plastic_bag
  其他异物   other_foreign_object

数据特点：

-   样本数量较少；
-   小目标较多；
-   部分类别形态变化明显；
-   场景复杂度有限。

------------------------------------------------------------------------

## 3.2 半自动标注流程

由于原始图片缺少检测标签，首先人工标注部分图片。

随后：

1.  使用部分人工标签训练初始YOLO模型；
2.  利用模型预测剩余未标注图片；
3.  生成伪标签；
4.  人工检查并修正。

最终形成完整YOLO格式数据集。

该流程降低了大量人工框选成本，提高了数据制作效率。

------------------------------------------------------------------------

# 4. Baseline模型建立

## 4.1 初始训练

采用：

    YOLOv8n

原因：

-   模型轻量；
-   推理速度快；
-   适合部署。

训练配置：

  参数         设置
  ------------ ------
  Epoch        100
  Image size   640
  Batch        8

------------------------------------------------------------------------

## 4.2 Baseline问题

初始模型mAP50约为0.65，未达到项目目标。

主要问题：

### 小目标漏检

远距离异物占据像素较少，特征提取不足。

### 类别泛化不足

塑料袋等目标形态变化大，检测稳定性不足。

### 数据量限制

133张图片难以充分训练深度模型。

------------------------------------------------------------------------

# 5. 多轮模型优化

针对Baseline问题进行了多轮实验。

## 5.1 训练策略优化

最终采用：

-   AdamW优化器；
-   降低学习率；
-   延长训练过程；
-   增强训练稳定性。

相比默认训练策略，更适合小规模目标检测任务。

------------------------------------------------------------------------

# 6. 数据增强优化

(augment_yolo_dataset_v2.py)

针对输电线路异物特点设计针对性增强策略：

## 光照增强

模拟不同天气和光照条件。

## HSV增强

提升颜色变化适应能力。

## 随机裁剪

增强模型对小目标和局部区域的识别能力。

## 类别平衡增强

重点增强：

-   plastic_bag
-   other_foreign_object

降低类别不均衡影响。

# 10. 技术难点与解决方案

## 数据量不足

解决：

-   数据增强；
-   半自动标注；
-   参数优化。

## 标注成本高

解决：

人工标注 + AI辅助标注 + 人工修正。

## 泛化能力不足

解决：

-   AdamW优化；
-   学习率调整；
-   困难类别增强。

## 工程复现问题

解决：

-   相对路径；
-   统一配置；
-   完善文档。

# 12. 项目不足与未来改进

## 数据规模不足

当前原始数据只有133张，未来需要增加不同地区、天气和线路环境数据。

## 测试集规模有限

测试样本数量较少，未来需要扩大独立测试集。

## 小目标检测仍可提升

未来可尝试：

-   更高输入分辨率；
-   YOLOv8s等更大模型；
-   多尺度检测结构。
