# Project Structure（项目结构说明）

## 1. 项目概述

本项目为输电线路异物检测（Transmission Line Foreign Object Detection）项目，采用 Python + YOLOv8 框架开发，实现输电线路巡检图像中的鸟巢、气球、塑料袋及其他异物的自动检测。

为了保证项目具有良好的可维护性、可扩展性及团队协作能力，项目采用标准化目录结构，将数据、代码、模型、实验结果及文档进行统一管理。

---

# 2. 项目目录结构

```text
Pole_AI_Project/
│
├── data/                      # 数据集目录
│   ├── raw/                   # 原始图片
│   ├── labels/                # YOLO标注文件
│   ├── train/                 # 训练集
│   ├── val/                   # 验证集
│   └── test/                  # 测试集
│
├── docs/                      # 项目文档
│
├── models/                    # 模型配置文件
│
├── notebooks/                 # Jupyter Notebook实验
│
├── reports/                   # 数据分析报告、实验报告
│
├── results/                   # 模型训练及推理结果
│
├── src/                       # Python源代码
│   ├── analysis/              # 数据分析（EDA）
│   ├── inspection/            # 数据检查
│   ├── inference/             # 模型推理
│   ├── training/              # 模型训练
│   └── utils/                 # 工具函数
│
├── weights/                   # 模型权重
│
├── README.md                  # 项目说明
│
└── requirements.txt           # Python依赖库
```

---

# 3. 各目录功能说明

## 3.1 data

用于统一管理整个项目的数据资源。

目录包括：

| 文件夹      | 功能                  |
|----------| ------------------- |
| raw      | 保存未经处理的原始图像数据       |
| labels   | 保存YOLO格式标签文件（*.txt） |
| train    | 训练集图片及标签            |
| val      | 验证集图片及标签            |
| test     | 测试集图片及标签            |

说明：

所有数据均统一存放于 data 目录，不在其他目录存放数据，保证数据管理规范。

---

## 3.2 docs

用于存放项目技术文档。

主要包括：

* 项目结构说明
* 模型调研报告
* 基线模型方案
* 评估指标说明
* 数据集说明
* 标注规范
* 开发文档

说明：

docs 目录仅保存说明性文档，不保存实验结果。

---

## 3.3 models

用于保存模型配置文件。

例如：

* YOLO模型配置（yaml）
* 自定义网络结构配置
* 超参数配置文件

说明：

模型配置与模型权重分离管理，方便版本控制。

---

## 3.4 notebooks

用于保存 Jupyter Notebook。

主要用于：

* 算法验证
* 数据可视化
* 临时实验
* 快速原型开发

说明：

Notebook 仅用于实验，不作为正式项目代码。

---

## 3.5 reports

用于保存项目过程中生成的报告。

包括：

* 数据分析报告
* 实验报告
* 周报
* 模型评估报告
* 项目总结

说明：

所有正式文档统一归档，便于项目管理及成果整理。

---

## 3.6 results

用于保存程序运行产生的结果。

包括：

* 推理结果图片
* Loss曲线
* PR曲线
* 混淆矩阵
* TensorBoard日志
* 模型训练结果

说明：

results 中所有内容均可重新生成，不作为源代码管理对象。

---

## 3.7 src

src 为整个项目的核心代码目录。

所有 Python 程序均放置于此。

目录划分如下：

### inspection

负责完成数据集检查。

主要功能：

* 数据统计
* 图片读取
* 图像格式检查
* 分辨率统计
* 数据完整性检查


---

### analysis

负责探索性数据分析（EDA）。

主要功能：

* Pandas统计分析
* Seaborn可视化
* Matplotlib绘图
* 数据分布分析



---

### inference

负责模型推理。

主要功能：

* 加载YOLO模型
* 单张图片推理
* 批量图片推理
* 视频推理
* 保存预测结果


---

### training

负责模型训练。

主要功能：

* 加载数据集
* 模型训练
* 模型验证
* 超参数设置
* 保存最佳模型


---

### utils

保存公共工具函数。

例如：

* 文件处理
* 图像处理
* 数据集工具
* 可视化工具

说明：

避免重复编写相同代码，提高项目可维护性。

---

## 3.8 weights

用于保存模型权重。

主要包括：

| 文件         | 说明       |
| ---------- | -------- |
| yolov8n.pt | 官方预训练模型  |
| best.pt    | 当前最佳模型   |
| last.pt    | 最近一次训练模型 |

说明：

模型权重与代码分离，便于模型版本管理。

---

* 安装方式

* 开发流程

说明：

README 是整个项目的说明入口。

# 4. 项目开发规范

为了保证项目具有良好的工程规范，制定以下开发要求：

1. 所有 Python 源代码统一存放于 src 目录；
2. 原始数据不得直接修改，统一保存在 data/raw；
3. 模型权重统一保存在 weights；
4. 所有实验结果统一保存在 results；
5. 所有技术文档统一保存在 docs；
6. 所有实验报告统一保存在 reports；
7. Notebook 仅用于实验验证，不作为正式项目代码；
8. Git 提交采用功能模块划分，每完成一个独立功能进行一次 Commit；
9. 项目采用模块化开发，避免重复代码，提高可维护性。

---

# 5. 总结

本项目采用标准化的软件工程目录结构，对数据、代码、模型、文档及实验结果进行分类管理，使项目具有良好的可维护性、可扩展性和团队协作能力。该目录结构符合 Python 工程开发规范，同时满足 YOLOv8 目标检测项目的开发需求，可支持后续数据标注、模型训练、模型评估及部署等工作，为整个输电线路异物检测项目提供统一、规范的工程基础。
